## 1. 前置概念（零基础必读）

### 1.1 Node.js 是什么，为什么前端项目需要它

- **浏览器只会做三件事**：解析 HTML、执行 JS、渲染 CSS。
- 浏览器**看不懂** `.vue` 文件、看不懂 `import` 语法、看不懂 Less。
- 所以在"写代码"和"浏览器能跑"之间，必须有一个**翻译官**。这个翻译官跑在电脑上，不在浏览器里。
- **Node.js 就是让 JavaScript 能在电脑上（而不是浏览器里）运行的环境**。
  vue-cli、webpack、babel 全都是用 JS 写的程序，靠 Node 跑起来。

```
你写的 .vue / .less / import 语法
        ↓ Node 上跑的 webpack + vue-loader + babel + less-loader（翻译官）
浏览器能懂的 .js + .css
```

**验证一下**：

```powershell
node -v      # v24.21.0   ← Node 的版本
npm -v       # 11.19.0    ← npm 的版本
```

`npm` = **N**ode **P**ackage **M**anager，Node 自带的"包管理器"，
作用类似手机的应用商店：从网上下载别人写好的代码库（比如 vue、echarts）。

### 1.2 什么是"构建"（build）和"开发服务器"（dev server）

| | `npm run serve`（开发） | `npm run build`（生产） |
|---|---|---|
| 产物 | **不落盘**，全在内存里 | 生成 `dist/` 目录 |
| 速度 | 快，改一个文件只重编译那一个 | 慢，要压缩、抽离、混淆 |
| 用途 | 边写边看 | 交给服务器部署 |
| 特点 | 自带热更新（HMR） | 体积小，可上线 |

本项目现在**没有 `dist/` 目录**，就是因为一直只用 `serve`，没打过包。

### 1.3 终端 / PowerShell 是什么

终端 = **用打字代替点鼠标**来操作电脑。你要让它"进入某个文件夹"，再说"执行某条命令"。

三个必会命令：

```powershell
pwd                     # 我现在在哪个目录
dir                     # 这个目录里有什么（Linux/macOS 是 ls）
Set-Location "D:\xxx"   # 进入某个目录（等价于 cd）
```

⚠️ 关于中文路径：这个项目的路径里有中文和括号 `(1)`，所以推荐用

```powershell
Set-Location -LiteralPath "D:\微信\...\jinggangshanLarge-master"
```

`-LiteralPath` 的意思是"按字面理解这串字符，别把括号当特殊符号"。

**怎么确认自己在正确的位置**：

```powershell
dir
```

能看到 `package.json` 就对了。**`npm run serve` 必须在有 `package.json` 的目录里执行**，
否则会报 `ENOENT ... package.json`。

### 1.4 端口是什么

一台电脑上可以同时跑很多"服务"，靠**端口号**区分。

- `localhost` = `127.0.0.1` = "我自己这台电脑"
- `8080` = 这个项目占用的端口
- `http://localhost:8080` = "访问我电脑上 8080 端口的那个服务"

所以：**同一个端口同一时间只能被一个程序占用**。这就是 `EADDRINUSE :8080` 的由来。

### 1.5 浏览器 DevTools 怎么用（本课全程要用）

按 **F12**（或右键 → 检查）打开，重点三个面板：

| 面板 | 看什么 | 什么时候用 |
|---|---|---|
| **Elements** | 真实 DOM 结构、样式 | 布局错位、样式不生效 |
| **Console** | JS 报错、`console.log` | 页面白屏、点击没反应 |
| **Network** | 每个请求的 URL/参数/返回 | 数据不显示、"接口对不对" |

Network 面板三个技巧：
1. 勾 **Fetch/XHR** 只看接口请求；
2. 点某条请求 → **Preview/Response** 看后端真实返回；
3. 勾 **Disable cache** 避免看到旧结果。

## 3. 三条命令的完整生命周期

### 3.1 `npm install` 到底做了什么

```
你: npm install
  ↓
npm 读 package.json 的 dependencies / devDependencies
  ↓
解析依赖树（vue 依赖什么、echarts 依赖什么…）递归求解
  ↓
对照 package-lock.json 锁定精确版本（保证你和我装的一样）
  ↓
从 registry（默认 registry.npmjs.org）下载 .tgz 压缩包
  ↓
解压到 node_modules/ 目录
  ↓
执行 postinstall 脚本（少数包需要编译原生模块）
```

**实测数据**：

- 装了 **1576 个包**，耗时约 2 分钟；
- `node_modules` 占 **297MB、39738 个文件**；
- 这解释了为什么"删了重装很慢"、为什么"复制项目别连 node_modules 一起拷"。

**三个常见疑问**：

| 疑问 | 答案 |
|---|---|
| `package.json` 和 `package-lock.json` 有什么区别？ | 前者写"版本范围"（`^5.4.0`），后者写"精确版本 + 下载地址 + 校验值"。**要提交 lock，不要手动改它** |
| 为什么会有 `devDependencies` 和 `dependencies` 之分？ | 前者只在开发/构建时需要（eslint、vue-cli），后者会进最终产物（vue、echarts）。`npm install --production` 会跳过 dev 依赖 |
| 这个项目有个 `"require": "^2.4.20"` 是什么？ | npm 上一个和 Node 内置 `require` 同名的老包，**完全没用**，建议删 |

> 副作用记录：npm 11 在安装时把 `package-lock.json` 的 `lockfileVersion` 从 2 升到了 3（400845 → 411388 字节）。正常行为。

### 3.2 `npm run serve` 到底做了什么

```
你: npm run serve
  ↓
npm 在 package.json 的 scripts 里找到 "serve": "vue-cli-service serve"
  ↓
执行 vue-cli-service（它是 @vue/cli-service 提供的命令）
  ↓
读 vue.config.js（端口、代理、路径前缀）
读 babel.config.js（怎么降级语法）
读 .eslintrc.js（要不要报错）
  ↓
把上面这些合并成一份 webpack 配置
  ↓
启动 webpack-dev-server
   ├─ 监听 8080 端口
   ├─ 把 src/main.js 当入口，递归分析 import，编译成一个 bundle（放内存）
   └─ 开一条 WebSocket（sockjs），用于热更新通知
  ↓
输出 "App running at: http://localhost:8080"
```

**关键理解**：dev server 期间**磁盘上没有产物**，`dist/` 不会出现。
你在浏览器看到的 JS，是 dev server 从内存里吐出来的。

**为什么改代码浏览器会自己变**（热更新 HMR）：

```
你保存文件
  → webpack 监听到文件变化，只重编译受影响的那几个模块
  → 通过 WebSocket 通知浏览器
  → vue-hot-reload-api 用新组件"替换"旧组件实例（保留当前状态，不刷新页面）
```

这就是为什么改样式是"瞬间"生效、偶尔改 `data` 结构时必须手动刷新。

## 4. `package.json` 逐字段

```json
{
  "name": "agri-big-screen",
  "version": "0.1.0",
  "private": true,
  "scripts": {
    "serve": "vue-cli-service serve",
    "build": "vue-cli-service build",
    "lint": "vue-cli-service lint"
  },
  "dependencies": { ... },
  "devDependencies": { ... },
  "eslintConfig": { ... },
  "browserslist": ["> 1%", "last 2 versions", "not dead"]
}
```

| 字段 | 含义 | 本项目情况 |
|---|---|---|
| `name` | 包名 | `agri-big-screen` = 农业大屏，**不是"井冈山"**，说明它是多基地基座 |
| `version` | 版本 | `0.1.0`，从没发过正式版 |
| `private` | 禁止发布到 npm | `true`，防止误传 |
| `scripts` | 命令别名 | 三条都是 vue-cli 内置的 |
| `dependencies` | 运行时要用的包 | vue / echarts / three / element-ui … |
| `devDependencies` | 只在构建时用 | eslint / webpack / sass-loader … |
| `eslintConfig` | 内联的 ESLint 配置 | 和 `.eslintrc.js` 重复（两份规则并存） |
| `browserslist` | 目标浏览器范围 | 决定 babel 降到多老、CSS 加哪些前缀 |

### 4.1 `browserslist` 为什么重要

```json
["> 1%", "last 2 versions", "not dead"]
```

意思是：支持"全球使用率 >1% 的浏览器 + 各浏览器最近 2 个版本 + 没停止维护的"。
这会影响：

1. **babel 要不要把 `?.`、`async` 转成老写法**；
2. **autoprefixer 要不要加 `-webkit-` 前缀**；
3. **core-js 要不要注入 Promise/Array.includes 等 polyfill**。

### 4.2 5 个僵尸依赖（有证据）

| 包 | 证据 | 结论 |
|---|---|---|
| `d3` | `src/` 里搜 `from "d3"` → 0 处 | 白装 |
| `jquery` | 搜 `jquery` → 0 处 | 白装 |
| `lodash` | 搜 `lodash` → 0 处 | 白装 |
| `vue-resource` | 用了 axios，从没 import | 白装 |
| `require` | npm 上的同名老包 | 建议删 |

另外 `less` / `less-loader` 放在 `dependencies` 里也不对（它们只在构建时用，应在 `devDependencies`）。

## 5. `vue.config.js` 逐行

```js
module.exports = {
  runtimeCompiler: true,
  publicPath: "./",
  assetsDir: "large",
  devServer: {
    port: 8080,
    hot: true,
    proxy: {
      "/api": {
        target: "http://121.5.9.113:8090",
        secure: false,
        changeOrigin: true,
        pathRewrite: { "^/api": "" },
      },
    },
  },
};
```

### 5.1 `runtimeCompiler: true`

| 问题 | 答案 |
|---|---|
| 它是什么 | 让打出来的 Vue **带上模板编译器**（能在 JS 里写 `template: "<div>{{a}}</div>"`） |
| 本项目需要吗 | **不需要**。所有模板都在 `.vue` 里，已由 vue-loader 预编译 |
| 证据 | `src/` 里 `template:` 只有 14 处，全是 EZUIKit 播放器的参数字符串 |
| 删掉会怎样 | 一切照常，包体小 10~20KB（gzip） |

### 5.2 `publicPath: "./"`

| 值 | 打包后 HTML 里是 | 部署到子目录 |
|---|---|---|
| `"/"`（默认） | `<script src="/large/js/app.js">` | ❌ 404 |
| `"./"`（本项目） | `<script src="./large/js/app.js">` | ✅ 正常 |

这是"把 dist 拷到任意目录就能跑"的关键。

### 5.3 `assetsDir: "large"`

默认产物分布是 `js/`、`css/`、`img/`；改成 `large` 后全部塞进 `large/` 下。

**实测证据**（dev 环境抓首页 HTML）：

```html
<script src="large/js/chunk-vendors.js"></script>
<script src="large/js/app.js"></script>
```

访问 `/js/app.js` → **404**；访问 `/large/js/app.js` → **200**。

### 5.4 `devServer.proxy`

| 配置 | 作用 |
|---|---|
| `"/api"` | 匹配所有以 `/api` 开头的请求 |
| `target` | 转发到 `http://121.5.9.113:8090` |
| `secure: false` | 目标用 https 自签证书时不去校验 |
| `changeOrigin: true` | 把请求头 `Host` 改成目标域名，骗过后端域名校验 |
| `pathRewrite: {"^/api": ""}` | 去掉 `/api` 前缀再转发 |

**规则**：`/api/get-cities` → `http://121.5.9.113:8090/get-cities`

**但它基本没生效**，因为页面写的是绝对地址：

```js
this.$get("http://121.5.9.113:8090/mountain", { topicId: "35" })
```

axios 遇到绝对 URL 会**忽略 baseURL、也不经过 devServer** → 代理形同虚设，
跨域能通只是因为**后端配了 CORS**。

全项目只有一处真用到代理：`YuganAqua` 里 `axios.get("/api/get-cities")`。

## 6. `public/index.html` 逐段

### 6.1 头部三行

```html
<!DOCTYPE html>
<html lang="">
<head>
  <meta charset="utf-8">
  <meta http-equiv="X-UA-Compatible" content="IE=edge">
  <meta name="viewport" content="width=device-width,initial-scale=1.0">
  <meta http-equiv="Content-Security-Policy">
  <link rel="icon" href="<%= BASE_URL %>favicon.ico">
  <title>智慧农业采集信息展示系统</title>
```

| 行 | 作用 | 本项目的问题 |
|---|---|---|
| `<!DOCTYPE html>` | 告诉浏览器用标准模式 | 没问题 |
| `lang=""` | 空语言标记 | 应该是 `zh-CN` |
| `charset="utf-8"` | 编码 | 必须，否则中文乱码 |
| `X-UA-Compatible` | 让老 IE 用最新内核 | 历史遗留 |
| `viewport` | 移动端缩放 | 大屏用不上，但无害 |
| `Content-Security-Policy`（**值为空**） | 想限制资源加载 | **等于没写**，可以删 |
| `<%= BASE_URL %>` | vue-cli 注入的模板变量 | 值 = `publicPath` = `./` |
| `<title>` | 标签页标题 | 想改就改这里 |

### 6.2 那 200 行 CSS 和转圈动画

```html
<div id="app">
  <div id="loader-wrapper">
    <div id="loader"></div>
    <div class="loader-section section-left"></div>
    <div class="loader-section section-right"></div>
    <div class="load_title">正在加载中...</div>
  </div>
</div>
```

CSS 里定义了三层同心圆旋转（`#loader` / `:before` / `:after`），
还有一套 `.loaded` 状态下的"两侧幕布拉开"动画。

**关键发现**：这套 `.loaded` 动画**从来没被触发**——
我搜过整个项目，没有任何 JS 在执行 `classList.add("loaded")`。它是死代码。

**那转圈是怎么消失的？**

Vue 2 的 `vm.$mount("#app")` 内部做的是：

```js
el.parentNode.replaceChild(vm.$el, el)   // 用渲染好的新元素，替换掉旧的 #app
```

而 `#loader-wrapper` 在 `#app` **里面** → 被一起扔掉了。
所以"loader 消失"不是动画演的，是**元素被整体替换**了。

**验证**：把 `main.js` 最后一行注释掉，页面会**永远**停在转圈。

### 6.3 `noscript`

```html
<strong>We're sorry but <%= htmlWebpackPlugin.options.title %> doesn't work properly without JavaScript enabled.</strong>
```

`htmlWebpackPlugin.options.title` 取的是 `package.json` 的 `name`（`agri-big-screen`），
所以这句英文里会出现 `agri-big-screen` —— 而 `<title>` 又是中文，**两处不一致**。

## 7. `src/main.js` 逐行

```js

Vue.use(scroll);
Vue.use(VueAwesomeSwiper);

// ⑥ 请求拦截器
axios.interceptors.request.use((config) => {
  if (config.url == "http://121.5.9.113:8090/api/v1/export")
    config.headers.Authorization = window.localStorage.getItem("token");
  console.log(config);
  return config;
});

// ⑦ 挂到原型上
Vue.prototype.$echarts = echarts;
Vue.prototype.$post = postRequest;
Vue.prototype.$get = getRequest;
Vue.prototype.$average = average;
Vue.prototype.$pushData = pushData;
Vue.prototype.$getBarTime = getBarTime;
Vue.prototype.$axios = axios;

Vue.config.productionTip = false;

// ⑧ 挂载
new Vue({ router, store, render: (h) => h(App) }).$mount("#app");
```

| 段 | 作用 | 逐行要点 |
|---|---|---|
| ① | 引入壳和路由状态 | `App.vue` 是根组件；`router`/`store` 是对象，不是组件 |
| ② | 第三方库 | **`import "xxx.css"` 没有 `from`**，是"加载样式"的写法，不是导入变量 |
| ③ | 本地函数 | `{ postRequest, getRequest }` 是**具名导入**，名字必须和 `export` 的一致 |
| ④ | 副作用 | `chalk.js` 不导出任何东西，但执行时会 `echarts.registerTheme('chalk', {...})`。**import 一次就注册了** |
| ⑤ | 插件注册 | `Vue.use()` 会调用插件的 `install()`，全局注册组件/指令 |
| ⑥ | 拦截器 | 见 7.3（有 bug） |
| ⑦ | 原型挂载 | 见 7.2 |
| ⑧ | 挂载 | `render: h => h(App)` 是**渲染函数**写法，`h` 是 `createElement` 的别名 |

### 7.1 为什么 import 顺序不能乱

```js
import * as echarts from "echarts";   // 必须先：chalk.js 内部要拿 echarts 注册主题
import "./assets/js/chalk";
import "element-ui/lib/theme-chalk/index.css";
import "./assets/css/global.css";     // 放最后：可覆盖 element 的默认样式
```

`chalk.js` 是 UMD 模块，内部自己又 `require('echarts')` 了一次。
顺序反了通常不报错，但如果项目里出现**两份 echarts 实例**，
主题会注册到另一份上 → 图表变白底（极难排查）。

### 7.2 `Vue.prototype.$xxx` 是什么

Vue 的每个组件实例都继承自 `Vue.prototype`。往原型上挂东西，等于给**所有组件**加了一个属性/方法：

```js
Vue.prototype.$get = getRequest
```

之后就相当于每个组件里都有：

```js
this.$get(url, params)     // 模板里可以直接 $get(...)
```

**好处**：不用在每个组件 `import`；**坏处**：来源不明显，容易被误认为全局函数。

本项目挂了 7 个：

| 原型属性 | 来源 | 典型用法 |
|---|---|---|
| `$echarts` | echarts 全量 | `this.$echarts.init(el, "chalk")` |
| `$get` | `getRequest` | `this.$get("/mountain", {topicId:"35"})` |
| `$post` | `postRequest` | 云台控制、萤石云 token |
| `$axios` | axios 原对象 | 登录、导出（要自定义 headers） |
| `$average` | `average.js` | 求平均值、字符串转数字 |
| `$pushData` | `average.js` | 每 13 条切一小时，算 6 个小时均值 |
| `$getBarTime` | `average.js` | 生成柱状图 X 轴时间标签 |

### 7.3 拦截器里的 bug

```js
if (config.url == "http://121.5.9.113:8090/api/v1/export")
```

`==` 是**全等比较**，一字不差才成立。而导出页实际请求的是：

```js
url: "http://121.5.9.113:8090/api/v1/allMsg/export"   // 多了 allMsg/
```

→ **条件永远不成立 → token 从来没被带上**。

修正版：

```js
axios.interceptors.request.use((config) => {
  const token = localStorage.getItem("token");
  if (token && config.url.includes("/export")) {
    config.headers.Authorization = token;
  }
  return config;
});
```

顺带：`console.log(config)` 会把 token 打进控制台，属于信息泄露。

## 8. `App.vue` 与 100% 高度之谜

```vue
<template>
  <div id="app">
    <router-view></router-view>
  </div>
</template>

<style>
#video5-container iframe,
#FxVideo1-container iframe,
#FxVideo2-container iframe {
  height: 100% !important;
  width: 100% !important;
}
</style>
```

### 8.1 为什么大屏能撑满

`global.css`：

```css
html, body, #app {
  width: 100%;
  height: 100%;
  padding: 0;
  margin: 0;
  overflow: hidden;
}
body {
  background: url("../images/bg3.png") no-repeat;
  background-size: 100% 100%;
}
```

链条是：

```
html(100%) → body(100%) → #app(100%) → .page(100%) → .page-content(64%) …
```

**少任何一环，大屏就会塌成一个小方块**（因为 `%` 需要父元素有确定高度）。
`overflow: hidden` 则是为了防止出现滚动条（大屏绝对不能滚动）。

### 8.2 那三条 `iframe` 样式为什么是全局的

EZUIKit 播放器会在容器里**动态插入 `<iframe>`**。
子组件用 `scoped` 时，选择器会被编译成 `[data-v-xxxx]` 属性选择器，
而**运行期插入的 DOM 没有那个属性** → 样式不生效。

所以只能写在全局（无 `scoped`）。`!important` 是为了压过播放器的内联样式。

## 9. 一次刷新的完整时序

```
① 终端: npm run serve
        └─ webpack-dev-server 监听 8080

② 浏览器: GET http://localhost:8080/
        └─ 返回 index.html（6.9KB，含 loader）
           └─ 里面只有 2 个 script:
              large/js/chunk-vendors.js   ← vue + echarts + element + three…
              large/js/app.js             ← main.js + router + store

③ 执行 app.js
        └─ main.js 依次：装插件 → 注册主题/样式 → 挂原型 → new Vue().$mount("#app")
              └─ #app 被整体替换（loader 顺手消失）

④ App.vue 渲染 → <router-view>
        └─ 读 location.hash = #/jinggang
              └─ 动态 import 对应 chunk（第一次会下载）
                    └─ JgMountain/ScreenPage.vue 执行 mounted → 发请求 → 渲染

⑤ 改代码保存
        └─ webpack 增量编译 → WebSocket 通知 → 组件热替换（不刷新页面）
```

**实测 Network 顺序**：

| # | 请求 | 说明 |
|---|---|---|
| 1 | `GET /` | 6.9KB 的 HTML |
| 2 | `GET /large/js/chunk-vendors.js` | 第三方公共包 |
| 3 | `GET /large/js/app.js` | 业务代码 |
| 4 | `GET /large/js/xxx.js` | 点进某个大屏才出现 |

## 11. 报错急救表

| 现象 | 原因 | 解决 |
|---|---|---|
| `ENOENT ... package.json` | 不在项目目录 | `dir` 确认能看到 `package.json` |

| 中文乱码 | 文件编码不是 UTF-8 | VS Code 右下角切 UTF-8 |

## 13. 小结 + 自测

### 一张图记住

```
npm run serve
  → webpack-dev-server(8080) 读 vue.config.js / babel / eslint
  → 浏览器拿 index.html（含 #app + loader）
  → 下 app.js + chunk-vendors.js
  → main.js: 装插件 → 副作用(chalk/global.css) → 挂原型 → new Vue().$mount("#app")
  → #app 被整体替换（loader 消失）
  → App.vue 的 <router-view>
  → hash 路由懒加载对应 ScreenPage chunk
  → 渲染成像素
```

### 四句话

1. `index.html` 是**坑**，`main.js` 是**挂载**，`App.vue` 是**壳**，`router` 决定**塞什么**。
2. `vue.config.js` 决定**怎么打包**（前缀、资源目录、端口、代理）。
3. `main.js` 的原型挂载决定**你能写什么语法**（`this.$get`）。
4. 首屏 loader 消失靠"元素被替换"，不靠 `.loaded` 动画（死代码）。

### 自测（答案见下）

1. `npm install` 和 `npm run serve` 分别产出什么？
2. `devDependencies` 里的包会进最终产物吗？
3. `publicPath: "./"` 解决了什么问题？
4. 首屏的转圈动画是谁弄消失的？
5. `Vue.prototype.$get = getRequest` 之后，`this.$get` 是什么？
6. 为什么 `import "./assets/css/global.css"` 不需要 `from`？
7. `process.env.NODE_ENV` 是运行时变量吗？
8. 大屏撑满屏幕依赖哪条链？

<details>
<summary>答案</summary>

1. `npm install` 产出 `node_modules/`（依赖）；`npm run serve` 不产出磁盘文件，只在内存里编译并提供 8080 访问。
2. 不会。dev 依赖只在开发/构建时用，`npm install --production` 会跳过。
3. 打包产物用相对路径引用资源，部署到任意子目录都不会 404。
4. Vue 挂载时 `replaceChild` 把整个 `#app`（含 loader）替换掉了。
5. 就是 `getRequest` 函数本身（挂在原型上，所有组件都能访问）。
6. 这是"只执行、不导入变量"的写法（副作用引入），用于加载 CSS。
7. 不是。webpack 在编译时把它**替换成字符串**（`"development"` / `"production"`）。
8. `html(100%) → body(100%) → #app(100%) → .page(100%)`，缺一环就塌。
</details>
