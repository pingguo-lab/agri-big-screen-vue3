### 2.2 与 Vue 2 的三处差异

| # | Vue 2 | Vue 3 | 说明 |
|---|---|---|---|
| 1 | `import VueRouter from "vue-router"` | `import { createRouter, createWebHashHistory } from "vue-router"` | **v4 没有默认导出** |
| 2 | `Vue.use(VueRouter)` | 不需要 | `app.use(router)` 在 main.js 里 |
| 3 | `mode: "hash"` | `history: createWebHashHistory()` | 模式变成"传一个 history 对象" |

`createWebHashHistory()` 等价于 Vue 2 的 `mode: "hash"`；`createWebHistory()` 等价于 `mode: "history"`。

> `beforeEach` **完全不变**：`(to, from, next)` 三个参数、必须调用 `next()`，和 v3 一模一样。
> 我加了 `to.path === "/error" ? false : "/error"` 是为了防止 `/error` 本身匹配失败时无限重定向（Vue 2 版没加，属于潜在死循环）。

### 2.3 懒加载在 Network 里长什么样

```js
component: () => import("../views/JgMountain/ScreenPage.vue")
```

1. 打开 `/#/navigation`，F12 → Network → 只看 JS：**2 个**请求（`chunk-vendors.js` + `app.js`）；
2. 点"井冈山黄桃"卡片 → **多 1 个** js 请求（就是 JgMountain 的 chunk）；
3. 再点别的基地 → 再多 1 个。

**为什么只 2 个**：webpack 把 `import()` 的模块单独切 chunk，用 JSONP 动态插 `<script>` 下载。

```html
<div class="menu">
  <div class="item"><yongxinLarge /></div>
  <div class="item"><ganzhouOrange /></div>
  <div class="item"><jinggangShan /></div>
  <div class="item"><XinjianEcoGarden /></div>

  <div class="item"><Fengxin></Fengxin></div>
  <div class="item"><yuganFish /></div>
  <div class="item"><mjy/></div>
  <!-- 保证每排 4 个组件，如果不符，此处的数字 -->
  <div class="item" v-for="(o, i) in 2" :key="i"></div>
</div>
```

```less
.menu {
  display: flex;
  flex-wrap: wrap;                 // 放不下就换行
  justify-content: space-evenly;   // 每行均分间隙
  height: 85%;
  overflow: auto;
  .item { margin: 20px auto; width: 400px; height: 250px; }
}
.menu::-webkit-scrollbar { display: none; }
```

**4 列的由来**：1920 宽，4 × 400 = 1600，剩 320 由 `space-evenly` 分成 5 份间隙。

**两个空 `div`**：`v-for="(o, i) in 2"` 渲染 2 个空盒子，保证"卡片数不是 4 的倍数时最后一行仍对齐"。
8 张卡片正好 4×2，这 2 个空格是给以后加卡片留的补丁 —— 加卡片时记得改这个数字。

> ⚠️ Vue 3 里 `v-for` 的 `key` 依然必须有，这里用的是索引，可以接受（纯静态占位）。

## 四、一张卡片：`src/components/yongxinLarge.vue`

### 4.1 结构

```
.home-container
├── .header-container        400×250 卡片本体
│   ├── .project-name        ← 左上角按钮，里面是 <router-link>
│   └── .mapInfo → .echartInfo  ← 小地图容器
├── .text                    ← 250×60 文字轮播（<swiper>）
└── .pics → .article-main    ← 300×170 图片轮播（两张图换 class）
```

### 4.2 标题按钮

```html
<router-link to="/yongxin">永新茶叶</router-link>
```

Vue 3 里 `<router-link>` 用法**完全不变**，仍然渲染成 `<a href="#/yongxin">`，点击不刷新页面。
`to` 必须和路由表里的 `path` **完全一致（区分大小写）**。

> 项目里有个历史 bug：`xiaofuchaye.vue` 写的是 `to="/Xiaofuchaye"`（大写 X），
> 路由注册的是 `/xiaofuchaye` → 点进去会跳 `/error`。这张卡片目前被注释掉了，所以没人发现。

### 4.3 小地图（Vue 3 版的写法）

```js
import yongxinMP from "../assets/js/yongxin.json";   // GeoJSON 直接当模块导入

methods: {
  initEchartInfo() {
    const echarts = this.$echarts;   // ★ Vue 2 版是 let echarts = require("echarts")

    echarts.init(document.getElementById("echartInfo")).dispose();   // 先销毁旧实例
    let myChart = echarts.init(document.getElementById("echartInfo")); // 再初始化
    echarts.registerMap("yongxin", yongxinMP);                        // 注册地图
    myChart.setOption(this.option);                                    // 设置配置
  },
}
```

**为什么这里不需要 `markRaw`（和第 06 课的图表组件不一样）**：

```js
let myChart = echarts.init(...)   // ← 局部变量，没有存进 data()
```

只有**存进 `data()` 的对象**才会被 Vue 3 的 Proxy 代理。
`ScreenPage` 里的图表组件把实例存进 `this.myChart`（在 data 里），所以那边必须 `markRaw`。

> 这条对比很重要：**问题不在于"用了 ECharts"，而在于"实例进了响应式系统"。**

### 4.4 那个 `id` 为什么是 `echartInfo` / `echartInfo2` … `echartInfo12`

8 张卡片**同时在 DOM 里**，`document.getElementById` 只返回第一个匹配。
所以原作者手工给每个卡片编了号。Vue 3 里有更干净的做法：

```html
<div class="echartInfo" ref="echartInfo"></div>
```
```js
this.myChart = markRaw(echarts.init(this.$refs.echartInfo));
```

`ref` 是 Vue 管理的引用，天然不冲突。

### 4.5 文字轮播：`<swiper>`（Vue 3 兼容层）

```html
<div class="text" style="overflow: hidden">
  <swiper :options="swiperOption">
    <swiper-slide><p>在永新，有一座崖石山，海拔近千米……</p></swiper-slide>
    <swiper-slide><p>崖雾茶采摘精细，制作精巧……</p></swiper-slide>
    <swiper-slide><p>具有提神、利尿、健胃……</p></swiper-slide>
  </swiper>
</div>
```

```js
import { swiper } from "@/compat/swiper";   // ★ Vue 2 是 vue-awesome-swiper

swiperOption: {
  pagination: { el: ".pagination-home", clickable: true },   // 死配置：页面里没有这个元素
  loop: true,
  autoplay: { delay: 10000, disableOnInteraction: false },
},
```

**Vue 3 为什么不能直接用 `vue-awesome-swiper`**：那个库是 Vue 2 的插件（`Vue.use` + `$children` 那一套），
Vue 3 跑不起来。迁移时写了一个 80 行的兼容层（`src/compat/swiper.js`），
支持 `:options` 里的 `autoplay.delay`、`loop`、点击 `.swiper-button-prev/next` 切换。

**能力缺口**：没有触摸滑动、没有分页圆点（不过原来那套分页配置本来就没生效）。

### 4.6 图片轮播（假轮播，Vue 3 下完全没变）

```html
<img src="../assets/images/chaye.webp"       :class="v1" />
<img src="../assets/images/chatian-min.webp" :class="v2" />
```

```less
.wz3 { width: 280px; height: 160px; left: 15px; top: 2px; z-index: 999; }  // 大图在前
.wz2 { width: 50%; left: 100px; top: 20px; z-index: 888; }                 // 小图在后
```

```js
toRight() { this.value++; if (this.value > 2) this.value = 1; this.changeClasss(); },
changeClasss() {
  if (this.value == 1) { this.v1 = "banner wz3"; this.v2 = "banner wz2"; }
  if (this.value == 2) { this.v1 = "banner wz2"; this.v2 = "banner wz3"; }
},
```

**本质**：两张图绝对定位叠着，换 class 换前后位置 + `transition` 出动画。
加第三张图就要再加一套 `.wz1`（样式已经写好但没人用）。

## 七、自测

1. `new VueRouter({mode:"hash"})` 在 v4 里怎么替代？
2. 为什么 `import VueRouter from "vue-router"` 会报错？
3. 首页为什么是 8 张卡片 + 2 个空 div？空 div 删了会怎样？
4. 卡片里的 echarts 为什么不用 `markRaw`，而 `ScreenPage` 里的图表组件要用？
5. `registerMap` 和 `series.map` 是什么关系？

<details><summary>答案</summary>

1. `createRouter({ history: createWebHashHistory(), routes })`。
2. vue-router 4 只有具名导出，没有 `export default`。
3. 8 张卡片铺 4×2；2 个空 div 占位让"卡片数不是 4 的倍数"时最后一行仍对齐，删了不报错但加卡片后会错位。
4. 卡片里 `myChart` 是**局部变量**，没进 `data()`，不会被 Proxy 代理；图表组件把实例存进 `data`，必须 `markRaw`。
5. `registerMap` 是"注册"地图数据，`series.map` 是"引用"这个名字，两者必须一致，否则画不出来。
</details>
