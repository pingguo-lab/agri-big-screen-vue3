## 二、路由表：`src/router/index.js`

### 2.1 创建方式（与 Vue 2 的三处差异）

```js
// Vue 2
import VueRouter from "vue-router";
Vue.use(VueRouter);
const router = new VueRouter({ mode: "hash", routes });

// Vue 3（本项目）
import { createRouter, createWebHashHistory } from "vue-router";
const router = createRouter({
  history: createWebHashHistory(),   // 等价于 mode: "hash"
  routes,
});
```

| # | Vue 2 | Vue 3 | 说明 |
|---|---|---|---|
| 1 | `import VueRouter from "vue-router"` | `import { createRouter, createWebHashHistory } from "vue-router"` | **v4 没有默认导出** |
| 2 | `Vue.use(VueRouter)` | 不需要（`app.use(router)` 在 main.js） | —— |
| 3 | `mode: "hash"` | `history: createWebHashHistory()` | 模式变成一个 history 对象 |

三类写法：

| 写法 | 含义 | 例子 |
|---|---|---|
| `redirect` | 只跳转，不渲染组件 | `/` → `/navigation` |

### 2.4 404 兜底

```js
router.beforeEach((to, from, next) => {
  if (to.matched.length === 0) {
    next(to.path === "/error" ? false : "/error");   // 防死循环
  } else {
    next();
  }
});
```

- `to.matched` 是"匹配到的路由记录数组"，一个都没匹配 = 空数组；
- `next(false)` = 中止导航，避免 `/error` 本身也匹配失败时无限重定向（原始项目没这层判断）。

### 4.2 `<router-link>`

```html

```

⚠️ `to` 必须和 `path` 完全一致（区分大小写）。项目里 `xiaofuchaye.vue` 写的是 `/Xiaofuchaye`（大写 X），

### 4.3 小地图：`registerMap` 全流程

```js
import yongxinMP from "../assets/js/yongxin.json";   // GeoJSON 直接当模块导入

methods: {
  initEchartInfo() {
    const echarts = this.$echarts;     // Vue 2 版是 require("echarts")

    echarts.init(document.getElementById("echartInfo")).dispose();      // ① 先销毁旧实例
    let myChart = echarts.init(document.getElementById("echartInfo"));  // ② 再初始化
    echarts.registerMap("yongxin", yongxinMP);                          // ③ 注册地图
    myChart.setOption(this.option);                                     // ④ 设置配置
  },
}
```

```js
option: {
  series: [{
    type: "map",
    map: "yongxin",                                              // ★ 与 registerMap 名字一致
    itemStyle: { emphasis: { areaColor: "rgb(147,235,248)" } },  // 悬停高亮
    label: { show: false },                                       // 不显示地名
    data: [{ name: "永新县", value: 360830 }],
  }],
}
```

**六个知识点：**

1. JSON 可直接 `import`：webpack 原生支持 `.json`，不用 loader
2. `registerMap(名字, GeoJSON)` 是**注册**，`series.map` 是**引用**，两者必须一致，否则画不出来
3. `data` 里的 `name`（"永新县"）要和 GeoJSON 的 `properties.name` 对上，否则不高亮
4. `init().dispose()` 是"先建再毁"：避免重复 init 报 "instance already initialized"
5. **为什么这里不用 `markRaw`**：`myChart` 是**局部变量**，没进 `data()`，不会被 Proxy 代理
   （对比：`ScreenPage` 里的图表组件把实例存进 `this.myChart`（在 data 里），所以那边必须 `markRaw`）
6. 容器 id 是手工编号 `echartInfo` / `echartInfo2` … `echartInfo12`：
   因为 8 张卡片同时在 DOM 里，`getElementById` 只返回第一个。更好的写法是 `ref`

### 4.4 文字轮播（`<swiper>` 兼容层）

```html
<swiper :options="swiperOption">
  <swiper-slide><p>在永新，有一座崖石山…</p></swiper-slide>
  ...
</swiper>
```

```js
import { swiper } from "@/compat/swiper";   // Vue 2 是 vue-awesome-swiper

swiperOption: {
  pagination: { el: ".pagination-home", clickable: true },  // 死配置（页面没这个元素）
  loop: true,
  autoplay: { delay: 10000, disableOnInteraction: false },
},
```

**为什么不能直接用 `vue-awesome-swiper`**：它是 Vue 2 插件（`Vue.use` + `$children` 那一套）。
兼容层实现了 `autoplay.delay`、`loop`、箭头点击；**没有**触摸滑动和分页圆点。

### 4.5 图片"轮播"其实是换 class

```html
<img src="../assets/images/chaye.webp"      :class="v1" />
<img src="../assets/images/chatian-min.webp" :class="v2" />
```

```less
.wz3 { width: 280px; height: 160px; left: 15px; top: 2px; z-index: 999; }  // 大图在前
.wz2 { width: 50%; left: 100px; top: 20px; z-index: 888; }                 // 小图在后
```

```js
toRight() { this.value++; if (this.value > 2) this.value = 1; this.changeClasss(); },
changeClasss() {
  if (this.value == 1) { this.v1 = "banner wz3"; this.v2 = "banner wz2"; }
  if (this.value == 2) { this.v1 = "banner wz2"; this.v2 = "banner wz3"; }

```

两张图绝对定位叠着，换 class 换前后位置 + `transition` 出动画。加第三张图得再加一套 `.wz1`。

## 七、自测

1. `new VueRouter({mode:"hash"})` 在 v4 里怎么替代？
2. 为什么 `import VueRouter from "vue-router"` 会报错？
3. 首页为什么是 8 张卡片 + 2 个空 div？空 div 删了会怎样？
4. 卡片里的 echarts 为什么不用 `markRaw`，而 `ScreenPage` 里的图表组件要用？
5. `registerMap` 和 `series.map` 是什么关系？

<details><summary>答案</summary>

1. `createRouter({ history: createWebHashHistory(), routes })`。
2. vue-router 4 只有具名导出，没有 `export default`。
3. 8 张卡片铺 4×2；2 个空 div 让"卡片数不是 4 的倍数"时最后一行仍对齐，删了不报错但加卡片后会错位。
4. 卡片里 `myChart` 是局部变量，没进 `data()`；图表组件把实例存进 `data`，必须 `markRaw`。
5. `registerMap` 是注册地图数据，`series.map` 是引用这个名字，必须一致，否则画不出来。
</details>
