## 一、第 01 课修订：启动链路

### 1.1 结论没变的部分（可以照旧理解）

- `public/index.html` 的坑 + loader 动画 + `#app` 被整体替换 ✅ 完全一样
- `html → body → #app → .page` 的 100% 高度链 ✅ 完全一样
- `vue.config.js` 的 `publicPath: "./"`、`assetsDir: "large"`、devServer.proxy ✅ 一样
- 浏览器只加载 2 个同步 script（`app.js` + `chunk-vendors.js`）、路由懒加载 ✅ 一样

### 1.2 变了的 5 处

**① 入口文件从 46 行变 64 行**

```js
// 旧（Vue 2）
import Vue from "vue";
Vue.use(ElementUI);
Vue.prototype.$echarts = echarts;
new Vue({ router, store, render: (h) => h(App) }).$mount("#app");

// 新（Vue 3）
import { createApp } from "vue";
const app = createApp(App);
app.use(ElementPlus);
app.config.globalProperties.$echarts = echarts;
app.mount("#app");
```

**② 多装了两个兼容层 + 一个错误兜底**

```js
import DataViewCompat from "./compat/data-view";
import SwiperCompat from "./compat/swiper";
app.use(DataViewCompat);
app.use(SwiperCompat);
app.component("vue-seamless-scroll", SeamlessScroll);

app.config.errorHandler = (err, instance, info) => {   // 新增：把错误定位到组件名
  console.error("[VUE-ERR]", err?.message, "component:", instance?.$options?.__file, info);
};
```

**③ `chalk.js` 从 UMD 改成了 ESM**

```js
// 旧：UMD 包装（webpack 4 下走 CommonJS 分支）
(function (root, factory) { ... factory(exports, require('echarts')); }(this, function (exports, echarts) { ... }));

// 新：直接 ESM + IIFE（因为原来函数体里有 return，不能裸露在模块顶层）
import * as echarts from "echarts";
(function () { ... echarts.registerTheme("chalk", {...}); })();
```

> 为什么要改：webpack 5 对 UMD 的分支判断和 4 不一样；改成 ESM 后行为确定，不再"看运气"。

**④ `runtimeCompiler` 这个配置没了**

Vue 2 版 `vue.config.js` 有 `runtimeCompiler: true`（当时就没用上）。Vue 3 版直接删掉，
因为模板全部在 `.vue` 里由 compiler-sfc 预编译。

**⑤ 构建器换了内核**

| | 旧 | 新 |
|---|---|---|
| vue-cli | 4.5（webpack 4） | 5.0（**webpack 5**） |
| Node 内置模块 polyfill | 自动带上 | **不再自动**（所以 mqtt 改了引入方式） |

**这条是第 01 课最该更新的认知**：webpack 4 会偷偷帮你 polyfill `url`/`path`/`buffer`，
webpack 5 不会——报错形如 `Module not found: Can't resolve 'url'`。

## 二、第 02 课修订：路由与首页导航

### 2.1 结论没变的部分

- 23 条路由的**清单**没变，仍然是 hash 模式 + 全部懒加载
- `router.beforeEach` 兜底 404 的逻辑没变
- 首页 8 张卡片 + 2 个占位 div + flex 4 列布局没变
- 卡片里画小地图的流程（GeoJSON → registerMap → series.map）没变

### 2.2 变了的 3 处

**① 路由实例的创建方式**

```js
// 旧
import VueRouter from "vue-router";
Vue.use(VueRouter);
const router = new VueRouter({ mode: "hash", routes });

// 新
import { createRouter, createWebHashHistory } from "vue-router";
const router = createRouter({ history: createWebHashHistory(), routes });
```

**② 卡片里的 `require("echarts")` 换成了全局属性**

```js
// 旧（Vue 2，webpack 4 下 require 能拿到模块）
initEchartInfo() {
  let echarts = require("echarts");
  echarts.init(document.getElementById("echartInfo")).dispose();
  ...
}

// 新（Vue 3，直接用 main.js 挂好的全局 echarts）
initEchartInfo() {
  const echarts = this.$echarts;
  echarts.init(document.getElementById("echartInfo")).dispose();
  ...
}
```

> 12 个卡片组件全部替换。好处：不再依赖 CommonJS 的 `require`，以后换 Vite 也不用改。

**③ 弹窗插槽写法**

```html
<!-- 旧 -->
<div slot="footer" class="dialog-footer">...</div>
<!-- 新 -->
<template #footer><div class="dialog-footer">...</div></template>
```

同时 `:visible.sync="x"` → `v-model="x"`（element-plus）。

## 三、第 03 课修订：请求层

### 3.1 结论没变的部分（这课几乎不用改）

- `utils/request.js` 的 `baseURL`、超时、请求拦截器 **原样保留**
- `$get` 返回 body、`$post` 返回整个 response 的**层级差异原样保留**
- `/mountain`、`/api/v1/msg`、`/api/v1/allMsg` 三套接口和 topicId 映射 **原样保留**
- 用浏览器直接调接口的调试方法 **原样保留**

### 3.2 变了的 3 处

**① main.js 里那个 token 拦截器的 bug 被修了**

```js
// 旧（永远不成立，token 从来没带上）
if (config.url == "http://121.5.9.113:8090/api/v1/export") { ... }

// 新（后缀匹配 + 空值判断）
const token = window.localStorage.getItem("token");
if (token && (config.url || "").includes("/export")) {
  config.headers.Authorization = token;
}
```

**② mqtt 改用浏览器构建**

```js
// 旧
import mqtt from "mqtt";
// 新（webpack 5 不 polyfill node 内置模块）
import mqtt from "mqtt/dist/mqtt.min.js";
```

涉及 `components/mqtt.vue`、`Fengxin/coldStorage/ScreenPage.vue`、`Mushroom/ScreenPage.vue`。

**③ axios 升级到 1.6.8**

`0.21` → `1.x`。本项目的用法（`axios.get(url,{params})`、`axios.interceptors.request.use`、`responseType:"blob"`）
在 1.x 下全部兼容，代码不用改。

## 四、一张总表：Vue 2 讲义 → Vue 3 现状

| 第 01–03 课里讲到的 | Vue 3 项目里变成 |
|---|---|
| `new Vue().$mount()` | `createApp().mount()` |
| `Vue.prototype.$xxx` | `app.config.globalProperties.$xxx` |
| `Vue.use(ElementUI)` | `app.use(ElementPlus)` |
| `Vue.use(borderBox8)` | `app.component("dv-border-box-8", ...)` |
| `new VueRouter({mode:"hash"})` | `createRouter` + `createWebHashHistory` |
| `new Vuex.Store` | `createStore` |
| `chalk.js` UMD | `chalk.js` ESM + IIFE |
| `runtimeCompiler: true` | 删除 |
| `require("echarts")` | `this.$echarts` |
| `require("...png")` | `import xx from "...png"`（webpack 5 下更稳） |
| `import mqtt from "mqtt"` | `mqtt/dist/mqtt.min.js` |
| `beforeDestroy` | `beforeUnmount` |
| `slot="footer"` | `<template #footer>` |
| `:visible.sync` | `v-model` |
| `this.myChart = echarts.init(...)` | `this.myChart = markRaw(echarts.init(...))` |
| 单根节点 | 允许多根（本项目模板未改，仍是单根） |
