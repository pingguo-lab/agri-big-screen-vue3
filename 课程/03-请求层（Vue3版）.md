## 二、前置知识（30 秒）

### axios 是什么

浏览器原生只有 `fetch` / `XMLHttpRequest`。axios 在 XHR 上封了一层，换来：
**自动 JSON 解析、统一拦截器、超时控制**。

### Promise 三态

```
pending → fulfilled（走 .then）
       ↘ rejected（走 .catch）
```

⚠️ 后端返回 `{"code":500}` 但 HTTP 状态 200 时**不会走 catch**，业务错误要自己判断 `res.data.code`。

### `params` vs `data`

| 位置 | 效果 |
|---|---|
| `params` | 拼到 URL：`GET /mountain?topicId=35` |
| `data` | 请求体（**GET 请求里会被忽略**） |

### `baseURL` 优先规则

```
axios.get("mountain")          → ${baseURL}/mountain      ✅
axios.get("/mountain")         → ${baseURL}/mountain      ✅
axios.get("http://1.2.3.4/x")  → http://1.2.3.4/x          ❌ 绝对地址，baseURL 被无视
```

项目里页面写的是绝对地址 → 所以 `devServer.proxy` 基本没生效。

## 三、`src/utils/request.js` 逐段（106 行）

### 3.1 配置区

```js
import axios from "axios";
import { buildMockResponse, isProjectApi } from "./mockData";   // ← 本课新增的降级层

const baseURL = "http://121.5.9.113:8090";
axios.defaults.baseURL = baseURL;
axios.defaults.timeout = 30000;
```

| 行 | 作用 | 不写会怎样 |
|---|---|---|
| `baseURL` | 请求公共前缀 | 每个请求都要写全地址 |
| `timeout = 30000` | 30 秒超时 | 后端无响应时页面一直"卡着" |

### 3.2 请求拦截器

```js
axios.interceptors.request.use(
  (config) => {
    if (config.url.includes("jxautts.top:444")) {
      config.url = config.url.replace("https://jxautts.top:444", baseURL);   // 老域名自动替换
    }
    config.baseURL = baseURL;   // 强制覆盖，防止别处改掉
    return config;              // ★ 必须返回
  },
  (error) => Promise.reject(error)
);
```

### 3.3 `postRequest` 与"四层数据模型"★

```js
export function postRequest(url, params) {
  return new Promise((resolve, reject) => {
    axios.post(url, params)
      .then((res) => resolve(res))      // ★ 停在"信封"层
      .catch((err) => reject(err));
  });
}
```

```
服务器 JSON 文本： {"code":200,"data":[{…}]}
        ↓ axios 自动 JSON.parse 并包进 response
第①层  response      = { status, headers, data:{code,data}, config }
        ↓ resolve(res)          ← $post 停在这
第②层  response.data = { code:200, data:[…] }            （后端 body）
        ↓ resolve(res.data)     ← $get 停在这
第③层  body.data     = [ {…}, {…} ]                       （记录数组）
        ↓ [0]
第④层  record        = { temperature:"10.40", ts:"…" }
```

```js
this.$post(url, p).then(res => res.data.data)   // 挖两层
this.$get(url, p).then(res => res.data)         // 挖一层
```

> 一句话：**`$post` 给信封，`$get` 已经帮你拆了信封。**

### 3.4 `getRequest`（本课重点：多了一个降级分支）

```js
export function getRequest(url, params) {
  return new Promise((resolve, reject) => {
    axios.get(url, { params: params })
      .then((res) => {
        const body = res.data;

        // ① 成功但数据为空：例如该网关没有历史数据
        const isEmpty = body && Array.isArray(body.data) && body.data.length === 0;
        if (isEmpty && isProjectApi(url)) {
          resolve(buildMockResponse(url, params));   // → 用示例数据
          return;
        }
        resolve(body);
      })
      .catch((err) => {
        // ② 请求失败：HTTPS 页面请求 HTTP 后端会被浏览器拦
        if (isProjectApi(url)) {
          resolve(buildMockResponse(url, params));   // → 用示例数据
          return;
        }
        reject(err);                                  // 登录、导出等不降级
      });
  });
}
```

**为什么要这层降级？**

线上 demo 是 `https://pingguo-lab.github.io/...`，后端是 `http://121.5.9.113:8090`。
浏览器按**混合内容（Mixed Content）**规则直接拦截 HTTP 请求 → 页面全是 0。
降级后：拿不到真数据就用示例数据，演示不至于"一片空白"。

**怎么区分真假数据**：控制台会打印

```
[mock] 接口不可用，已使用示例数据：http://121.5.9.113:8090/mountain (realTime)
```

**怎么关掉**：把 `request.js` 里两个 `if (... && isProjectApi(url))` 分支删掉即可。

## 四、示例数据：`src/utils/mockData.js`

```js
export function makeRecord(i = 0, base = new Date()) {
  const t = new Date(base.getTime() - (23 - i) * 3600 * 1000);  // 过去 24 小时
  const wave = Math.sin((i / 24) * Math.PI * 2);                 // 一天一个周期

  return {
    ts: fmt(t), receiveTime: fmt(t),
    temperature: round(14 + wave * 6, 1),     // 8~20℃
    humidity: round(62 - wave * 12, 1),       // 50~74%
    soilTemp: …, soilHum: …, co2: …, sunRadia: …, pm25: …, pm10: …,
    windSpeed: …, windDirection: (i % 8 + 8) % 8, rainfall: …,
    // 水产页专用：后端把"溶解氧/溶氧比/PH/氨氮"塞在 temp1~temp4
    temp1: …, temp2: …, temp3: …, temp4: …,
  };
}

export function buildMockResponse(url, params = {}) {
  const timeType = params.timeType || "realTime";
  let data;
  if (timeType === "realTime") data = [makeRecord(23)];   // 只要最新一条
  else if (timeType === "day") data = makeHourRecords(7);
  else data = makeHourRecords(24);                        // hour
  console.warn(`[mock] …`);                               // 让人能看出是假数据
  return { code: 200, success: true, message: "mock", data };
}
```

> 设计要点：**返回值结构必须和真实接口一致**（`{code, success, message, data}`），
> 这样页面代码一行都不用改。这也是"接口适配层"的通用做法。

## 七、现场实测（真实数据）

```powershell
# 浏览器直接打开
http://121.5.9.113:8090/mountain?topicId=35&timeType=realTime
```

| 请求 | 结果 |
|---|---|
| `topicId=35&timeType=realTime` | 11879 字节，有数据，第一条 `ts: "2025-11-17 02:20:01"` |
| `topicId=35&timeType=hour` | `{"code":200,…, "data":[]}` ← **空** |
| `topicId=35&timeType=day` | `data: []` |
| `topicId=9999&timeType=realTime` | `code:200, data:[]` ← 网关不存在也是 200 |

**三个结论：**

1. **数值是字符串**：`"temperature": "10.40"` → 所以到处是 `(x - 0).toFixed(2)`
2. **有脏数据**：`humidity: "104.90"`（物理上不可能超过 100%，传感器未校准）
3. **后端永远返回 200**：空数据也是 200 → 前端**无法区分**"网关挂了"和"没有数据"

第 3 条导致两种表现：

```js
resData.map(...)        // 空数组 → []      不报错，图空着
resData[0].temperature  // 空数组 → 抛 TypeError
```

## 八、三种写法

```js
// ① then（项目现状）
this.$get(url, { topicId: "35" }).then((res) => {
  this.real_airTemData = (res.data || [])[0]?.temperature ?? "0";
}).catch((e) => console.error(e));

// ② async/await（推荐）
async getData() {
  try {
    const res = await this.$get(url, { topicId: "35" });
    this.real_airTemData = (res.data || [])[0]?.temperature ?? "0";
  } catch (e) { console.error(e); }
}

// ③ 并发（多池塘场景）
const list = await Promise.all(ids.map((id) => this.$get(url, { topicId: id })));
```

> `??` 比 `||` 准：值是 `0` 时 `||` 会当假值，`??` 只对 `null/undefined` 生效。

## 九、5 个必踩错误

| # | 错误 | 现象 | 修法 |
|---|---|---|---|
| 1 | `res.map(...)` | `res.map is not a function` | `res.data.map(...)` |
| 2 | `axios.get(url, { data: p })` | 参数没发出去 | `{ params: p }` |
| 3 | 页面写绝对 URL | baseURL/proxy 全失效 | 写 `/mountain` |
| 4 | `res.data[0].x` | 空数组崩 | `(res.data \|\| [])[0]?.x ?? "0"` |
| 5 | 循环里 `await` | 串行，慢 N 倍 | `Promise.all` |

## 十一、自测

1. `$get(...).then(res => res)` 的 `res` 是什么？`$post` 的呢？
2. 为什么到处写 `(item.temperature - 0).toFixed(2)`？
3. `data: []` 时，`resData.map()` 与 `resData[0].x` 分别怎样？
4. mock 降级的两个触发条件是什么？为什么要加？
5. `baseURL` 什么时候不生效？

<details><summary>答案</summary>

1. `$get` 给 body（`{code,data}`）；`$post` 给整个 axios response（差一层）。
2. 后端数值是字符串，`.toFixed` 是 Number 的方法，`- 0` 做隐式转换。
3. `.map()` 返回 `[]` 不报错；`[0].x` 抛 TypeError。
4. ① 请求抛错（HTTPS 混合内容被拦）；② 返回了空数组。为让线上演示不空白。
5. url 是绝对地址（`http://...`）时。

</details>
