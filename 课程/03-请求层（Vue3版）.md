## 二、前置知识（30 秒复习）

### 2.1 axios 是什么

浏览器原生只有 `fetch` / `XMLHttpRequest`。axios 在 XHR 上封了一层，换了三件事：
**自动 JSON 解析、统一拦截器、超时控制**。

### 2.2 Promise 三态

```
pending → fulfilled（走 .then）
       ↘ rejected（走 .catch）
```

⚠️ 后端返回 `{"code":500}` 但 HTTP 状态 200 时，**不会走 catch**。要自己判断 `res.data.code`。

### 2.3 `params` vs `data`

| 位置 | 效果 |
|---|---|
| `params` | 拼到 URL：`GET /mountain?topicId=35` |
| `data` | 放进请求体（**GET 里会被忽略**） |

### 2.4 `baseURL` 的优先规则

```
axios.get("mountain")          → ${baseURL}/mountain        ✅
axios.get("/mountain")         → ${baseURL}/mountain        ✅
axios.get("http://1.2.3.4/x")  → http://1.2.3.4/x            ❌ 绝对地址，baseURL 被无视
```

本项目页面写的是绝对地址 → 所以 proxy 基本没生效。

## 三、`src/utils/request.js` 全文逐段

### 3.1 配置区

```js
import axios from "axios";

const baseURL = "http://121.5.9.113:8090";
axios.defaults.baseURL = baseURL;
axios.defaults.timeout = 30000;
```

| 行 | 作用 |
|---|---|
| `const baseURL` | 抽成常量（仍硬编码，理想做法是 `.env`） |
| `axios.defaults.baseURL` | 之后 `/mountain` 自动拼成完整地址 |
| `timeout = 30000` | 30 秒超时 |

> Vue 3 版没改这里。**唯一要注意的是 axios 从 0.21 升到了 1.6.8**，
> `baseURL`/`params`/`interceptors`/`responseType: "blob"` 这些用法**完全兼容**，代码不用动。

### 3.2 请求拦截器

```js
axios.interceptors.request.use(
  (config) => {
    // 老代码里写的是旧域名，统一替换成新 IP
    if (config.url.includes("jxautts.top:444")) {
      config.url = config.url.replace("https://jxautts.top:444", baseURL);
    }
    // 强制覆盖 baseURL，防止被别处改掉
    config.baseURL = baseURL;
    return config;                       // ★ 必须返回
  },
  (error) => Promise.reject(error)
);
```

**两个坑**：

1. `config.url.includes(...)` 在 url 为 `undefined` 时会抛错 → 稳妥写法 `(config.url || "").includes(...)`；
2. `return config` 忘了写，请求会以 `undefined` 发出去。

### 3.3 `postRequest` 与四层数据模型 ★

```js
export function postRequest(url, params) {
  return new Promise((resolve, reject) => {
    axios.post(url, params)
      .then((res) => { resolve(res); })       // ★ 停在"信封"层
      .catch((err) => { reject(err); });
  });
}
```

```
服务器 JSON 文本： {"code":200,"data":[{…}]}
        ↓ axios 自动 JSON.parse 并包进 response
第①层  response      = { status, headers, data:{code,data}, config }
        ↓ resolve(res)          ← postRequest 停在这
第②层  response.data = { code:200, data:[…] }            （后端 body）
        ↓ resolve(res.data)     ← getRequest 停在这
第③层  body.data     = [ {…}, {…} ]                       （记录数组）
        ↓ [0]
第④层  record        = { temperature:"10.40", ts:"…" }
```

```js
this.$post(url, p).then(res => res.data.data)   // 挖两层
this.$get(url, p).then(res => res.data)         // 挖一层
```

> 一句话：**`$post` 给信封，`$get` 已经帮你拆了信封。**

### 3.4 `getRequest`

```js
export function getRequest(url, params) {
  return new Promise((resolve, reject) => {
    axios.get(url, { params: params })       // ★ 注意是 { params }
      .then((res) => { resolve(res.data); }) // ★ 只返回 body
      .catch((err) => { reject(err); });
  });
}
```

```js
// 你写
this.$get("/mountain", { topicId: "35", timeType: "hour" })
// 实际请求
GET http://121.5.9.113:8090/mountain?topicId=35&timeType=hour
```

### 3.5 这层的 4 个遗留问题

| # | 问题 | 影响 | 建议 |
|---|---|---|---|
| 1 | `baseURL` 硬编码 | 换环境要改代码 | 用 `.env` |
| 2 | `$get`/`$post` 解包层级不一致 | 调用方要记两套 | 统一 `resolve(res.data)` |
| 3 | `new Promise` 多余包装 | 代码长、易漏 `resolve` | 直接 `return axios.get(...)` |
| 4 | 没有响应拦截器 | 401/500 无人统一处理 | 加 `interceptors.response` |

## 四、`main.js` 里的 token 拦截器（Vue 3 版已修好）

```js
// Vue 2 版（有 bug：永远不成立）
if (config.url == "http://121.5.9.113:8090/api/v1/export") { ... }

// Vue 3 版（修好了）
axios.interceptors.request.use((config) => {
  const token = window.localStorage.getItem("token");
  if (token && (config.url || "").includes("/export")) {
    config.headers.Authorization = token;
  }
  return config;
});
```

**原来为什么是 bug**：导出页请求的是 `.../api/v1/allMsg/export`，多了 `allMsg/`，全等比较永远 false
→ **token 从来没被带上**。

**Vue 3 版的三点改进**：

1. 后缀匹配 → 所有 `/export` 结尾的接口都能带上 token；
2. `token` 判空 → 不会把 `"null"` 字符串写进请求头；
3. 删掉了 `console.log(config)` → 不再把 token 打到控制台。

> axios 1.x 里 `config.headers` 是 `AxiosHeaders` 实例，`config.headers.Authorization = token`
> 依然有效（内部有 setter）。也可以写 `config.headers.set("Authorization", token)`。

## 五、现场实测：接口长什么样

### 5.1 自己调接口的 3 种方式

```powershell
# 浏览器地址栏（最快）
http://121.5.9.113:8090/mountain?topicId=35&timeType=realTime

# PowerShell
Invoke-WebRequest -Uri "http://121.5.9.113:8090/mountain?topicId=35&timeType=realTime" -UseBasicParsing |
  Select-Object -ExpandProperty Content

# F12 → Network → 点请求 → Response
```

### 5.2 三个接口的真实返回（同一张表，同一套结构）

| 接口 | 实测长度 | 第一条记录时间 |
|---|---|---|
| `/mountain?topicId=35&timeType=realTime` | 11879 字节 | `2025-11-17 02:20:01` |
| `/api/v1/msg?topicId=31&timeType=realTime` | 11507 字节 | `2026-03-20 05:38:39` |
| `/api/v1/allMsg?topicId=37&timeType=realTime` | 11886 字节 | `2026-04-05 17:10:05` |

```json
{
  "code": 200, "success": true, "message": "ok",
  "data": [{
    "topic": "31", "clientId": "31-1", "area": "zgdq",
    "ts": "2026-03-20 05:38:39",
    "temperature": "11.5", "humidity": "98.2", "illuminance": "0",
    "co2": "672", "sunRadia": "3", "soilTemp": "54.9",
    "soilHum": "", "conductivity": "", "pm25": "9", "pm10": null,
    "windSpeed": "0", "windDirection": 0, "rainfall": "", "allRainfall": null
  }]

```

### 5.3 三个必须知道的发现

**① 数值都是字符串或 null**

```js
(item.temperature - 0).toFixed(2)   // "11.5" - 0 → 11.5 → "11.50"
```

`"" - 0` = `0`、`null - 0` = `0`、`"abc" - 0` = `NaN` —— 所以项目里到处是 `x ? x : "0"` 兜底。

**② 有真实脏数据**

井冈山那条 `humidity: "104.90"` —— 相对湿度不可能超过 100%，传感器没校准。
前端没做范围校验，直接显示 104.90%rh。

**③ 请求不存在的网关，依然返回 200**

```powershell
GET /mountain?topicId=9999&timeType=realTime
→ {"code":200,"success":true,"message":"ok","data":[]}
```

**前端无法区分**"网关挂了""网关不存在""这段时间没采集"——全都长一样。于是两种表现：

```js
resData.map(...)        // 空数组 → []    不报错，图空着
resData[0].temperature  // 空数组 → 抛 TypeError: Cannot read property 'temperature' of undefined
```

### 5.4 `timeType` 实测

```powershell
timeType=realTime → 11879 字节，有数据
timeType=hour     → data: []
timeType=day      → data: []
```

→ **大屏上折线图空着不是前端 bug**，是 35 号网关只有实时数据、没有历史聚合。

| 字段 | 含义 | 单位 |
|---|---|---|
| `temperature` / `humidity` | 空气温/湿度 | ℃ / %rh |
| `soilTemp` / `soilHum` | 土壤温/湿度 | ℃ / %rh |
| `illuminance` | 光照 | lx |
| `sunRadia` | 太阳辐射 | W/㎡ |
| `co2` | CO2 | ppm |

## 六、在组件里怎么用（3 种写法）

### 写法 1：`then`（项目现状）

```js
getData() {
  this.$get("http://121.5.9.113:8090/mountain", {
    topicId: "35",
    timeType: "realTime",
  }).then((res) => {
    const rec = (res.data || [])[0] || {};
    this.real_airTemData = rec.temperature || "0";
  }).catch((err) => {
    console.error("取数失败", err);
  });
}
```

### 写法 2：`async/await`（推荐）

```js
async getData() {
  try {
    const res = await this.$get("/mountain", { topicId: "35", timeType: "realTime" });
    const rec = (res.data || [])[0] || {};
    this.real_airTemData = rec.temperature ?? "0";
  } catch (e) {
    console.error("取数失败", e);
  }
}
```

> `??` 比 `||` 更准：值是 `0` 时 `||` 会当成假值，`??` 只对 `null/undefined` 生效。

### 写法 3：并发

```js
// ❌ 串行：6 个池塘 = 6 次等待
for (const id of ids) { await this.$get(url, { topicId: id }); }

// ✅ 并发：同时发
const list = await Promise.all(ids.map((id) => this.$get(url, { topicId: id })));
```

余干水产有 6 个池塘（topic 37/40/41/42/43/44），串行要 6 个 RTT，并发只要 1 个。

## 七、5 个必踩错误

| # | 错误写法 | 现象 | 正确写法 |
|---|---|---|---|
| 1 | `res.map(...)` | `res.map is not a function` | `res.data.map(...)` |
| 2 | `axios.get(url, { data: p })` | 参数没发出去 | `{ params: p }` |
| 3 | `this.$get("http://1.2.3.4/x")` | baseURL/proxy 全失效 | `this.$get("/x")` |
| 4 | `res.data[0].temperature` | 空数组时崩 | `(res.data \|\| [])[0]?.temperature ?? "0"` |
| 5 | 循环里 `await` | 串行，慢 N 倍 | `Promise.all` |

## 八、mqtt 为什么要改引入方式（Vue 3 迁移的真实坑）

```js
// Vue 2 版（webpack 4 能跑）
import mqtt from "mqtt";

// Vue 3 版（webpack 5 报 Can't resolve 'url'）
import mqtt from "mqtt/dist/mqtt.min.js";
```

**原因**：`mqtt` 的 Node 构建依赖 `url`、`buffer`、`stream` 等 Node 内置模块。
webpack 4 **会自动 polyfill**，webpack 5 **不再自动**。

两条路：① 用浏览器构建（本项目选的）；② 在 `vue.config.js` 里配：

```js
configureWebpack: {
  resolve: {
    fallback: {
      url: require.resolve("url/"),
      buffer: require.resolve("buffer/"),
      stream: require.resolve("stream-browserify"),
    },
  },
},
```

涉及文件：`components/mqtt.vue`、`Fengxin/coldStorage/ScreenPage.vue`、`Mushroom/ScreenPage.vue`。

## 十、自测

1. `$get(...).then(res => res)` 的 `res` 是什么？`$post` 的呢？
2. 为什么项目里到处写 `(item.temperature - 0).toFixed(2)`？
3. `data: []` 时，`resData.map()` 和 `resData[0].x` 分别怎样？
4. `baseURL` 什么时候不生效？
5. webpack 5 为什么会报 `Can't resolve 'url'`？

<details><summary>答案</summary>

1. `$get` 给 body（`{code,data}`）；`$post` 给整个 axios response（`{status,headers,data:{code,data}}`）。
2. 后端数值是字符串，`.toFixed` 是 Number 的方法；`- 0` 做隐式转换。
3. `.map()` 返回 `[]` 不报错；`[0].x` 抛 TypeError。
4. url 是绝对地址（`http://...`）时。
5. webpack 5 移除了 Node 内置模块的自动 polyfill。
</details>
