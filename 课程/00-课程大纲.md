## 二、三课之间的逻辑

```
01 启动链路    → 页面是怎么"长"出来的（外壳与挂载）
02 路由与导航  → 页面之间怎么"选"（路由与首页）
03 请求层      → 数据是怎么"进"来的（接口与解包）
04 语法对照    → 上面三课里"过时的写法"统一换成 Vue 3
```

一句话：**01 讲"壳"，02 讲"路"，03 讲"数据"，04 讲"写法"。**
