## 二、零基础前置（四个概念）

### 1. Node.js：让 JS 在电脑上跑的环境

浏览器只懂 HTML / CSS / JS，**看不懂** `.vue`、`.less`、`import xxx from "yyy"`。
所以在"你写的代码"和"浏览器能跑的东西"之间，需要一个**翻译官**——这个翻译官跑在你电脑上。

```
.vue / .less / import 语法
   ↓ Node 上运行的 webpack + vue-loader + babel + less-loader（翻译官）
浏览器能懂的 .js + .css
```

`npm` 是 Node 自带的包管理器（类似应用商店），`npm install` 就是"按清单下载依赖"。

```powershell
node -v    # v24.21.0
npm -v     # 11.19.0
```

### 2. 构建 vs 开发服务器

| | `npm run serve` | `npm run build` |
|---|---|---|
| 产物 | **不落盘**，全在内存 | 生成 `dist/` |
| 速度 | 快，只重编译改动 | 慢，要压缩拆分 |
| 用途 | 边写边看（热更新） | 交给服务器部署 |

### 3. 终端三个命令

```powershell
pwd                        # 我在哪个目录
dir                        # 这里有什么
Set-Location -LiteralPath "D:\projects\jinggangshan-vue3"   # 进入目录
```

**`npm run serve` 必须在有 `package.json` 的目录里执行**，否则报 `ENOENT ... package.json`。

### 4. 端口 & DevTools

- `localhost:8080` = 本机 8080 端口；**同一端口同时只能被一个程序占用**
- F12 → **Console**（运行期报错）、**Network**（请求）、**Elements**（DOM/样式）

### 4.2 `vue.config.js`

```js
const { defineConfig } = require("@vue/cli-service");

module.exports = defineConfig({
  transpileDependencies: true,     // 依赖也用 babel 过一遍
  publicPath: "./",                // 产物用相对路径 → 丢任意目录都能跑
  assetsDir: "large",              // 静态资源进 dist/large/
  productionSourceMap: false,      // 生产不打 sourcemap
  devServer: {
    port: 8080,
    hot: true,
    proxy: {
      "/api": { target: "http://121.5.9.113:8090", changeOrigin: true, pathRewrite: { "^/api": "" } },
    },
  },
});
```

| 配置 | 作用 | 去掉会怎样 |
|---|---|---|
| `publicPath: "./"` | HTML 里资源引用变 `./large/js/...` | 部署到子目录 404（GitHub Pages 就是子目录） |
| `assetsDir: "large"` | 资源集中到 `large/` | 散在 `js/`、`css/`、`img/` |
| `proxy` | `/api/xxx` 转发到后端 | 只有写相对路径的请求用到（本项目多数写绝对地址，所以基本没生效） |

> 与 Vue 2 版差异：删掉了没用的 `runtimeCompiler`；构建内核从 webpack 4 升到 **5**。

## 五、`public/index.html`：转圈动画是谁弄没的

```html
<div id="app">
  <div id="loader-wrapper">
    <div id="loader"></div>
    <div class="loader-section section-left"></div>
    <div class="loader-section section-right"></div>
    <div class="load_title">正在加载中...</div>
  </div>
</div>
```

`#loader-wrapper` 在 `#app` **里面**。`app.mount("#app")` 会用它自己的渲染结果**替换 `#app` 的内容**，
于是 loader 连同它的 CSS 一起被扔掉。

> 那套 `.loaded` 动画 CSS 从来没被触发过（全项目没有任何 `classList.add("loaded")`），是死代码。
> **本次已删除**（`public/index.html` 里 38 行），首屏 loader 的消失逻辑不受影响。
>
> **验证**：注释掉 `app.mount("#app")`，页面永远转圈。

## 六、`src/main.js` 逐段（64 行，全项目最该背的文件）

```js
// ① 框架与壳
import { createApp } from "vue";        // Vue 2 是 import Vue from "vue"
import App from "./App.vue";
import router from "./router";
import store from "./store/store";

// ② 第三方
import * as echarts from "echarts";
import axios from "axios";
import ElementPlus from "element-plus";
import "element-plus/dist/index.css";

// ③ 本地工具
import { postRequest, getRequest } from "./utils/request.js";
import { average, pushData, getBarTime } from "./utils/average.js";

// ④ 副作用引入（没有 export，import 即执行）
import "./assets/js/chalk";        // 内部 registerTheme('chalk', ...)
import "./assets/css/global.css";  // html/body/#app 撑满 + 背景

// ⑤ Vue 3 兼容层
import DataViewCompat from "./compat/data-view";   // 内部就是 @kjgl77/datav-vue3
import SwiperCompat from "./compat/swiper";
import SeamlessScroll from "./compat/seamless-scroll";

// ⑥ 请求拦截器（原版 bug 已修：改成后缀匹配）
axios.interceptors.request.use((config) => {
  const token = window.localStorage.getItem("token");
  if (token && (config.url || "").includes("/export")) config.headers.Authorization = token;
  return config;
});

// ⑦ 创建应用
const app = createApp(App);
app.use(router); app.use(store); app.use(ElementPlus);
app.use(DataViewCompat); app.use(SwiperCompat);

// ⑧ 全局组件
app.component("vue-seamless-scroll", SeamlessScroll);

// ⑨ 全局属性（Vue 2 是 Vue.prototype.$xxx）
Object.assign(app.config.globalProperties, {
  $echarts: echarts, $post: postRequest, $get: getRequest,
  $average: average, $pushData: pushData, $getBarTime: getBarTime, $axios: axios,
});

// ⑩ 全局错误兜底：能打到具体组件
app.config.errorHandler = (err, instance, info) => {
  const name = (instance && instance.$options && (instance.$options.name || instance.$options.__file)) || "unknown";
  console.error("[VUE-ERR]", err && err.message, "| component:", name, "| info:", info);
};

// ⑪ 挂载
app.mount("#app");
```

### 逐段对照（Vue 2 → Vue 3）

| 段 | Vue 2 | Vue 3 | 为什么 |
|---|---|---|---|
| ① | `import Vue from "vue"` | `import { createApp } from "vue"` | Vue 3 没有默认导出 |
| ⑦ | `new Vue({ router, store, render: h => h(App) })` | `createApp(App)` + `app.use(...)` | 实例化与配置分离 |
| ⑧ | `Vue.use(borderBox8)` | `app.component("dv-border-box-8", C)` | `use` 只收插件 |
| ⑨ | `Vue.prototype.$get = …` | `app.config.globalProperties.$get = …` | 不再污染全局 |
| ⑩ | 无（要自己 `window.onerror`） | `app.config.errorHandler` | 内置，能拿到组件实例 |

### `$echarts` 为什么能省掉一堆 import

```js
app.config.globalProperties.$get = getRequest;
// 任何组件里都能：
this.$get("/mountain", { topicId: "35" });
// 模板里也能：
{{ $echarts.version }}
```

代价是**来源不透明**（看到 `$get` 不知道哪来的），大型项目更推荐显式 import。

### `chalk.js` 为什么改成了 ESM

原文件是 UMD 包装（`if (typeof exports === 'object') …`），在不同 webpack 版本下会走不同分支。
现在改成确定性的：

```js
import * as echarts from "echarts";
(function () {           // 原函数体里有 return，不能裸露在模块顶层
  echarts.registerTheme("chalk", { /* 400 行主题 */ });
})();
```

**验证**：主题没注册成功时，图表坐标轴文字会变成深灰（几乎看不见）。

## 八、一次刷新的完整时序

```
① npm run serve → webpack5 devServer(8080)
② GET / → index.html（含 #app + loader）
   └─ 2 个 script：large/js/chunk-vendors.js + large/js/app.js
③ 执行 app.js → main.js：app.use(...) → globalProperties → app.mount("#app")
   └─ #app 内容被替换（loader 消失）
④ App.vue → <router-view> → hash=#/jinggang → 懒加载对应 chunk → 渲染
⑤ 改代码保存 → 增量编译 → WebSocket → 组件热替换
```

**Network 验证**：首页只有 2 个 JS；点进某个大屏会多下载 1 个 chunk。

## 十、报错急救

| 现象 | 原因 | 处理 |
|---|---|---|
| `Module not found: Can't resolve 'url'/'path'` | **webpack 5 不再自动 polyfill Node 内置模块** | 用浏览器构建（如 `mqtt/dist/mqtt.min.js`）或配 `resolve.fallback` |
| `export 'default' was not found in 'vue'` | Vue 3 无默认导出 | `import { createApp } from "vue"` |
| `EADDRINUSE :8080` | 端口被占 | `netstat -ano \| findstr :8080` → `taskkill /PID xxx /F` |
| `ENOENT ... package.json` | 不在项目目录 | `dir` 确认能看到 `package.json` |
| `Failed to compile` | 语法错误 | 看第一条红字（带 文件:行号） |
| 白屏 + Console 红字 | 数据未到就渲染 | `v-if` 兜底或给初值 |
| 样式全丢 | 漏了 `element-plus/dist/index.css` | 检查 `main.js` 第 10 行 |
| 图表空白但无报错 | 接口返回空数组 | 用 mock 兜底 / 看 Network |

## 十一、自测

1. `npm run serve` 之后磁盘上有产物吗？
2. `createApp(App)` 和 `new Vue({ render: h => h(App) })` 的本质区别？
3. `app.config.globalProperties.$get` 和 `import { getRequest }` 各适合什么场景？
4. 为什么 webpack 5 会报 `Can't resolve 'url'`？
5. 首屏的转圈是谁弄消失的？

<details><summary>答案</summary>

1. 没有，全在内存；只有 `npm run build` 才产出 `dist/`。
2. 前者"每个应用一个实例"、配置不污染全局；后者是全局构造函数，全站共用一份配置。
3. 前者方便（模板里能直接用），但来源不透明；后者显式，适合大型项目与按需打包。
4. webpack 5 移除了 Node 内置模块的自动 polyfill（webpack 4 会偷偷带上）。
5. `app.mount("#app")` 用渲染结果替换了 `#app` 的内容，loader 在里面，于是被替换掉。
</details>
